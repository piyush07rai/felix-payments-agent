    How Felix Decouples LLMs from Enterprise Data

    Employees can query concrete transactions in Slack, Teams, or the Web UI. The Local Vault scrubs all identifiers before the prompt reaches Gemini, and rehydrates the results before display.

    User Platform Slack / Teams / Web "Check bd3aa0d0..."

    Local Vault PII Tokenizer Replaces with surrogate tokens
    ➔
    External LLM Gemini 3.8 Flash "WHERE txn_id = '{{TXN_REF_1}}'"
    ➔
    Tool Interceptor Enterprise DB Desanitizes query & scrubs rows
    ➔
    Local Vault Rehydrator "Txn bd3aa0d0 resolved"
